# audit 题库/流程审计检查清单

本文件用于快速检查一套技术面试题库、模拟面试流程或面试官工作流是否足够专业、完整、可执行。

---

## 一、面试目标检查

- [ ] 是否明确本轮面试的目标（初筛 / 一面 / 二面 / 终面 / 专项面）
- [ ] 是否明确要判断的核心能力，而不只是"多问些题"
- [ ] 是否区分本轮必须判断和非本轮重点判断的内容
- [ ] 是否有清晰的通过/不通过标准

---

## 二、候选人画像检查

- [ ] 是否明确候选人年限范围
- [ ] 是否明确目标层级（高级工程师 / TL / 架构方向）
- [ ] 是否明确技术栈边界（Python 后端 / 平台 / 数据 / 安全 / AI）
- [ ] 是否明确业务场景（ToB / ToC / 高并发 / 安全 / AI / 中台）

---

## 三、题目结构检查

- [ ] 是否有基础题
- [ ] 是否有深挖题
- [ ] 是否有项目题
- [ ] 是否有系统设计题
- [ ] 是否有稳定性 / 排障题
- [ ] 是否有行为与协作题
- [ ] 是否区分哪些题适合快问快答，哪些题适合深挖
- [ ] 是否有题目使用说明（时间建议、适用轮次）

---

## 四、专业度检查

- [ ] 是否覆盖原理深度，而不是只有定义
- [ ] 是否能区分"知道"与"做过"
- [ ] 是否有真实项目追问
- [ ] 是否有量化追问（QPS、数据量、延迟、成本等）
- [ ] 是否有 trade-off 追问
- [ ] 是否有故障处理、回滚、监控、审计意识
- [ ] 是否有边界条件和失败场景的考察

---

## 五、区分度检查

- [ ] 是否能识别只会背八股的候选人
- [ ] 是否能拉开普通工程师与高级工程师差距
- [ ] 是否有红旗信号
- [ ] 是否有加分信号
- [ ] 是否有能验证真实性的追问链
- [ ] 是否有能区分"参与"和"主导"的题目

---

## 六、评分与决策检查

- [ ] 是否有统一评分维度
- [ ] 是否有各维度的评分锚点
- [ ] 是否有通过 / 存疑 / 不通过的依据
- [ ] 是否有标准结论模板
- [ ] 是否能支持多位面试官对齐口径

---

## 七、执行可用性检查

- [ ] 是否适合线上面试表达方式
- [ ] 是否能在有限时间内完成
- [ ] 是否有模块优先级和时间分配建议
- [ ] 是否能被下一位面试官复用
- [ ] 是否能沉淀为组织资产（题库 / SOP / 模板）
- [ ] 题目是否有清晰的考察意图说明

---

## 八、个性化出题检查（适用于基于简历出题）

- [ ] 是否根据候选人技术栈定制题目
- [ ] 是否针对候选人项目经历设计追问
- [ ] 是否覆盖候选人声称负责的核心模块
- [ ] 是否有验证简历真实性的题目
- [ ] 是否有针对潜在风险点的考察
- [ ] 是否考虑了候选人的目标级别

- [ ] 是否有稳定性治理题目
- [ ] 是否有可观测性相关题目

- [ ] 是否有线上故障排查顺序题目
- [ ] 是否有模块边界设计题目
- [ ] 是否有风险识别与需求澄清题目
- [ ] 是否有技术债判断与重构边界题目

## 十二、审计执行建议

### 审计前
1. 明确审计目标（完整性审计 / 专业性审计 / 区分度审计）
2. 收集所有相关材料（题库、答案、评分标准、追问链）
3. 了解面试岗位和目标级别

### 审计中
1. 按上述清单逐项检查
2. 记录具体证据，不要只给主观判断
3. 识别优先级最高的问题

### 审计后
1. 输出结构化审计报告
2. 给出具体改进建议和优先级
3. 如需沉淀，说明沉淀方向（模板/SOP/skill）

## 十三、常见问题速查

| 问题类型 | 典型表现 | 建议动作 |
|----------|----------|----------|
| 题目太多，没有重点 | 题目数量超过 30 道，无优先级标注 | 按模块和时间重新组织，标注核心题和备选题 |
| 只有概念题，没有项目题 | 全是"什么是 X"类问题 | 增加项目落地题和实战排障题 |
| 没有评分标准 | 只有题目和答案，没有通过标准 | 增加评分维度和锚点 |
| 追问不够 | 每题只有 1 个追问或没有追问 | 增加原理追问、项目追问、量化追问 |
| 区分度不足 | 题目太简单或太难，无法拉开差距 | 增加中等难度题和深挖题 |
| 不适配线上面试 | 题目依赖 IDE 或需要写完整代码 | 改为口述方案、伪代码、关键配置类问题 |
| 缺少真实性校验 | 无法区分"背过"和"做过" | 增加角色边界题和量化追问 |
| 缺少红旗信号 | 没有明确淘汰标准 | 增加红旗信号列表 |
