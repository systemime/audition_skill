# audit 题目优先级标注体系

本文件定义面试题目的优先级标注规则，帮助面试官在有限时间内选择最有价值的题目。

---

## 优先级定义

### P0 - 必问题

**定义**：任何情况下都必须覆盖的题目，约3-5题

**特征**：
- 与岗位核心能力直接相关
- 能快速校准候选人水平
- 能识别明显不合格信号
- 覆盖关键真实性校验点

**时间占比**：约20-30%的面试时间

---

### P1 - 核心题

**定义**：根据岗位重点选择，约8-12题

**特征**：
- 与岗位重点能力强相关
- 能验证技术深度或项目真实性
- 有较好的区分度
- 适合大多数候选人

**时间占比**：约50-60%的面试时间

---

### P2 - 备选题

**定义**：时间充裕或需补验证时使用

**特征**：
- 用于补充验证某方面能力
- 可根据候选人表现灵活选择
- 适合特定背景的候选人
- 非必须覆盖

**时间占比**：约10-20%的面试时间

---

### P3 - 深挖题

**定义**：候选人某项目/领域特别熟时连续追问用

**特征**：
- 与候选人简历强关联
- 需要较深的项目背景才能回答
- 用于区分"参与"和"主导"
- 不适合所有候选人

**时间占比**：根据候选人表现动态调整

---

## 优先级标注方法

### 单题标注格式

```markdown
### [题号] [P级别]
**问题：** ...
**考察点：** ...
**优秀回答要点：** ...
**追问：** ...
```

### 示例

```markdown
### 1. [P0]
**问题：** 请你用3分钟介绍一下最近两份工作里，你最核心的技术产出分别是什么？
**考察点：** 经历真实性、总结能力
**优秀回答要点：**
- 能清晰区分"项目背景-职责-结果"
- 能指出自己真正负责的模块
- 能量化结果
**追问：** 哪个模块如果把代码拉出来给你，你最有把握讲清楚？

### 23. [P1]
**问题：** RefineAgent 用强约束 JSON 输出的主要价值是什么？
**考察点：** 结构化输出设计
**优秀回答要点：**
- 便于程序解析、路由、校验、重试
- 减少模型自然语言歧义
- 为后续字段提供稳定格式
**追问：** 如果模型经常输出非法 JSON，你如何治理？

### 156. [P2]
**问题：** 如果让你重新设计一次这个系统，你最想重做的部分是什么？
**考察点：** 复盘能力
**优秀回答要点：**
- 能指出真实问题
- 说明为什么当时这样做
- 说明现在会如何改
**追问：** 这个问题在上线初期暴露了吗？

### 78. [P3-项目A]
**问题：** 你在 mcp-portal 中 PlanAgent 的核心职责是什么？
**考察点：** 任务拆解能力理解
**优秀回答要点：**
- 不只是分类，还包括目标识别、子任务拆分、依赖顺序
- 要为后续工具调用准备结构化计划
**追问：** 怎么防止 PlanAgent 把简单问题拆得过细？
```

## 抽题策略

### 基础抽题公式

```
实际抽题 = P0全部 + P1按时间选 + P2按情况补 + P3按简历配
```

### 40分钟面试抽题示例

```
P0：5题（全部必问）
P1：8题（从12题中选择）
P2：3题（时间充裕时补）
P3：2-4题（根据简历匹配度选择）

总计：12-18题
```

### 60分钟面试抽题示例

```
P0：5题（全部必问）
P1：12题（从18题中选择）
P2：6题（时间充裕时补）
P3：4-6题（根据简历匹配度选择）

总计：18-28题
```

## 动态调整策略

### 根据候选人表现调整

| 候选人表现 | 调整策略 |
|-----------|----------|
| 表现优秀，回答有深度 | 增加 P1/P3 深挖题，减少 P2 |
| 表现一般，有亮点有短板 | 保持 P0+P1，针对性补 P2 |
| 表现不佳，明显不合格 | 快速完成 P0，提前结束 |
| 某项目特别熟悉 | 在该项目增加 P3 连续追问 |
| 某领域明显薄弱 | 在该领域增加 P1 验证 |

### 根据时间调整

| 时间情况 | 调整策略 |
|----------|----------|
| 时间充裕 | 增加 P2 备选题，延长 P3 深挖 |
| 时间紧张 | 只保留 P0 和部分 P1 |
| 超时风险 | 跳过 P2，减少追问次数 |

## 优先级检查清单

**生成题库后检查：**
- [ ] P0 题目是否覆盖核心能力
- [ ] P0 题目数量是否在3-5题范围内
- [ ] P1 题目是否与岗位重点匹配
- [ ] P3 题目是否与候选人简历关联
- [ ] 各优先级题目数量比例是否合理

**面试前检查：**
- [ ] 已选择本次面试要问的题目
- [ ] P0 题目全部包含
- [ ] P1 题目按时间预估选择
- [ ] 准备了备选题应对变化

**面试后检查：**
- [ ] P0 题目是否全部覆盖
- [ ] 是否因时间问题跳过了重要题目
- [ ] 优先级设置是否需要调整
